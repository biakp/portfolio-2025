# Bea Knabben — Portfolio

Bilingual portfolio for Beatriz Knabben, a front-end and Shopify Online Store 2.0 developer. Built for remote hiring conversations and fixed-price Shopify work.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- Deployed on Vercel

## What’s on the page

- Creative bento layout, EN / PT-BR toggle saved in `localStorage`
- Downloadable CVs: `public/Beatriz_Knabben_Resume.pdf` and `public/Beatriz_Knabben_Curriculo_PT.pdf`
- Employment at Check Commerce, Leadways, and freelance
- Engineering capabilities (no client store names or store URLs)
- Five fixed-price Shopify packages, shown in USD or BRL

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
```
